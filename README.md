# 《羊承千年》时光穿梭·寻羊千年

横版 16:9 HTML5 互动游戏，单文件 `index.html`（CSS/JS 全部内嵌），直接用浏览器打开即可玩。

## 玩法
首页时光之门 → 游戏说明 → 第一关时间轴 → 第二关文物年代排序（拖拽/点选放置，5 张）→ 第三关探索 4 展品集纹样 → 第四关羊纹设计工坊（羊角4/羊身3/纹样4/材质4/背景4 + 命名）→ 生成 1920×1080 PNG 海报下载 → 终章。

## 修改指南
- 文物数据：`ARTIFACTS` 数组（名称/年代/提示/详情）。四羊方尊为真实文物（商代晚期，58.3cm，约34.5kg，1938 湖南宁乡出土，中国国家博物馆藏）；其余 4 项标注“文化示意展项”，不得编造馆藏信息。
- 换图：卡片图为内联 SVG（`artSvg` 函数），替换为 `<img>` 或新 SVG 即可，勿引用不存在的路径。
- 羊角/羊身/纹样/材质：`HORNS / BODIES / PATTERNS / MATERIALS` 对象。
- PNG 导出：`exportPoster()` 用 Canvas 1920×1080 绘制，文件名 `羊承千年_<作品名>.png`。
- 存档：localStorage 键 `yang-shiguang-v1`。

## 修复记录（2026-11-22 00:35 完整功能测试后）
jsdom 28 项 + 补充 7 项断言全过（此前 23 项）。本次测试发现并已修复的真实问题：
1. **刷新恢复失效（最严重）**：启动时 `show("home")` 会把存档的 screen 冲成 home，“继续游戏”永远只能回说明页；`buildSort()` 只恢复了已放计数，卡片还留在托盘里，计数与画面不一致。已修：启动先记下 resumeTarget，首页不写盘；`buildSort()` 把已存卡片放回对应槽位。
2. **存档可能丢进度**：`save()` 把 1920×1080 海报的 data URL（几百 KB）也写进 localStorage，易超 5MB 配额静默失败。已修：保存时剔除 posterData，图只留内存，终章“保存”时若无图会重新导出。
3. **工坊点选项重建整个面板**：每次点击都重建 innerHTML，焦点/滚动丢失，旧按钮监听器挂在脱离文档的节点上。已修：只改 state + 原地切换 .on，面板 DOM 不动（用 data-cat 区分五类）。
4. **放错提示叠加**：放错时先提示“位置不对”，又叠加一句“未放到有效位置”。已修：只有根本没落在任何槽位上才提示弹回；槽位已有卡片时单独提示；补 pointercancel（手指滑出/来电打断不卡住）。
5. **重复加分**：刷新后重进再提交会重复 +500 分。已修：sortDone 守卫。
6. **终章 id 重复**：终章复制 goatSvg 会造出第二套 matGrad / pat-* id。已修：复制时改后缀 matGradF / pat-*F。
7. **矮屏横屏被裁**：手机横屏高约 360px 时排序/工坊内容超出被 overflow:hidden 裁掉。已修：高 ≤560px 时画面可滚动、卡片/槽位缩小、工坊三栏收窄；另加宽 ≤900px 与竖屏兜底。
8. **详情入口看不见**：卡片编号可点看详情但无任何提示。已修：编号加 title，排序页加文字说明。
仍需真机点验：触屏拖拽手感、PNG 在真机实际落盘（jsdom 里用模拟 Canvas/Image 验证了导出逻辑：1920×1080、羊形与作品名均画进去了）。
